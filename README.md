# VE 学習 — CVS / VES / VEリーダー 受験対策アプリ

VE（バリューエンジニアリング）資格試験の受験勉強用 Web アプリ。
サーバー・ログイン不要。データはすべてブラウザ内（localStorage）に保存されます。

## 収録問題と試験区分

すべての問題は **試験区分（`exams`）** を持ち、`CVS` / `VES` / `VEL`（VEリーダー）のいずれか（複数可）に属します。
演習・用語カード・ダッシュボードは区分で絞り込めます。

| 出典 | 区分 | 内容 |
|---|---|---|
| VES 試験対策の学習ノート（`ve-exam-notes.md`） | `VES` | 用語 72 / 正誤 83 / 選択 58 ＝ **213 問**（8分野） |
| CVS 基本問題 完全対策集 | `CVS` | 正誤 69 / 選択 51 / 用語 37 / 計算 13 / 説明 33 ＝ **203 問** |

> **注意:** 213 問の区分は出典に合わせて機械的に `VES` としており、内容から CVS / VEリーダー向けかどうかを
> 判定してはいません。正しい振り分けは利用者の判断で行ってください。
> 「管理 → 一覧 → **一括再タグ**」で複数選択して区分を 付与 / 解除 / 置換 でき、結果はブラウザ内に保存されて
> 再ビルドなしで出題に反映されます。

## 機能

| 画面 | 内容 |
|---|---|
| ホーム | 区分別の収録数・学習済み数、今日の復習件数、通算正答率、分野別正答率の横棒グラフ（区分で絞り込み可）、直近14日の学習数 |
| 演習 | 試験区分・分野・形式・問題数を選んで出題。即時採点＋解説。「苦手・復習優先」モードあり |
| カード | 用語カードをめくって自己採点。「あやふや」だけ周回するモード |
| 管理 | 全問一覧（区分・分野・形式・正答率でフィルタ、検索）、一括再タグ、自作問題の追加/編集、JSON インポート/エクスポート、記録リセット |

- 出題形式: 用語（4択） / 正誤 / 選択 / 説明（自由記述 → 模範解答で自己採点） / 計算（数値判定、記述式は自己採点）
- 間隔反復: ライトナー方式（正解で箱を1つ上げ、不正解で箱0へ。次回間隔 0/1/2/4/7/15/30日）
- キーボード操作: 正誤 `1`=○ `2`=×、選択 `1`〜`4`、説明・記述式は `1`=書けた `2`=書けなかった、`Enter`=次へ
- スマホ対応（下部タブバー）、ダークモード対応

## 問題データの追加

問題の追加・区分の指定方法は **[DATA-FORMAT.md](./DATA-FORMAT.md)** を参照。
再ビルド不要、画面上のインポートだけで反映されます。旧形式（schemaVersion 1）の JSON もそのまま取り込めます。

## 技術スタック

Next.js 16.3.5 (App Router) / React 19 / TypeScript / Tailwind CSS v4
外部 API・DB・チャートライブラリなし。グラフは自前のインライン SVG。

## 開発

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # 本番ビルド
npm run lint
```

## デプロイ

Vercel にこのリポジトリを Import するだけ。環境変数は不要です。
全ページが静的生成（SSG）されるため Hobby プランで無料運用できます。

## データの持ち出し

学習記録・自作問題・区分の振り直しは「管理 → データ → エクスポート」で JSON として保存できます。
端末を移すときや、ブラウザデータを消す前にエクスポートしてください。
